# GL uniform buffers and reflection design

Goal: complete shader_reflect -> uniform_write -> uniform_bind -> draw/dispatch for existing public0.5.0 APIs. Probe only, Windows DLL remains D3D11. No yy/yyp/manual export changes.

Binding ABI: raw GLSL physical UBO binding = stage*8+slot; vertex0..7, pixel8..15, compute16..23. Public stages0/1/2, slots0..7. Separate namespace from SSBO. Reflection reports logical slot = nativeBinding - stage*8. A reflected block outside that stage namespace must report a useful unsupported-binding error rather than silently choose a different block. Distinct block names are required for independent per-stage blocks; native cross-stage block linking rules apply. No source rewriting.

Use a new focused GL uniform module for lazy native reflection, UBO capabilities and persistent indexed claims. GL ShaderObject owns cached UniformLayout; first metadata query links a temporary separable program without changing the current program. Reflection failure is reported at query, preserving compile/bind transaction behavior and legacy GLSL120 compile. A successfully compiled compute shader without local size still compiles and still fails link only at bind (existing regression). Successful cached metadata survives graphics program relinks. Reflect active native blocks/members, offsets, block bytes, base scalar kinds, matrix orientation, array sizes and actual array/matrix strides. Unsupported types are metadata Unknown and rejected by writes. Struct leaves retain native qualified paths; strip only block prefix and terminal array[0] when exposing an array as one member.

Backend-neutral interfaces: shader_uniforms(uint64)->const UniformLayout*, uniform_buffer_bytes(uint64,const char*)->int64. Default metadata lookup may return nullptr; D3D override returns DeviceState shader uniforms and validates existing Uniform role. GL override returns its own shader layout and buffer metadata. Shared igpu_reflect.cpp must no longer directly require D3D ShaderEntry/BufferEntry for lookup or writes. Preserve existing D3D validation/messages where meaningful. No GL symbols in shared production DLL.

Internal UniformMember gains array_stride/matrix_stride default0. Packer uses queried strides, falling back to16 and majors*16 for old D3D metadata. Write span ends after last actual component: array stride*(elements-1) + matrix stride*(majors-1) + minors*4, or last vector/scalar component. Thus vec3 cannot erase a scalar at offset12. Unknown/Struct remain unwritable. Public reflection shape unchanged.

GL Uniform buffers use native subrange patches. Creation starts zero, partial writes preserve neighbors and Dynamic resize keeps GPU prefix/zeros growth. No duplicate CPU shadow is needed because BufferSubData supports subranges. Validate mapped/roles/size/range before modifying GPU data. Bind persists and restores caller indexed offset/size plus generic binding on unbind/release/shutdown. Late mapped claimed inputs are rejected before draw/dispatch. Capability requires true GL support, all reflection/binding/query entrypoints, >=24 physical UBO bindings, >=8 blocks per supported vertex/pixel/compute stage, positive native block size. Optional missing functions disable capabilities before use.

Acceptance: actual compute words, vertex/pixel pixels, scalar/vector/int/uint/bool, both matrix orders, arrays including single element, neighbor/padding preservation, zero/grow/shrink, cached reflection and invalid handles, transactional link failure, mapped resources, out-of-namespace block, all indexed/generic/program restoration, shutdown native cleanup. Full previous probe, DLL, handover, one branch review, feature PR merge.

Implementation rulings: native ordinary single-stage reflection fallback after separable failure supports valid non-separable vertex interfaces; observed RED out/uniform-graphics-run.log before fix. Double Unknown kinds keep native8-byte components and dimensions (observed RED out/uniform-double-red-run.log) while writes reject them. GL uses native subrange uploads, preserving external GPU bytes and avoiding a duplicate shadow.
