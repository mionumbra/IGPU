# GL geometry and tessellation stages

Complete native GLSL geometry(stage3), hull/TCS(stage4) and domain/TES(stage5) plus existing patch drawing as one capability batch. Preserve public0.5.0, no yy/yyp changes, D3D11 formal DLL and featurePR workflow; standing user authorization covers continuous implementation and merging.

Use a focused graphics helper for actual context/patch capability and program switch preflight. Graphics links are transactional: link a candidate before replacing the last valid program/binding map. Failed interface/program links keep previous bindings, current program and real pixels. Reject forbidden program changes during active unpaused transform feedback before mutation. Keep separate compute program behavior and reserved mesh/amplification unsupported.

Either tessellation bind order is accepted: an incomplete pair records its requested stage and links the otherwise valid VS/PS/GS pipeline with both tess stages omitted. Completing a pair attaches both. Unbinding either removes both from the native program while retaining the other requested binding; patch draws require both. A patch draw validates1..32 control points/native maximum, whole patches, safe inferred ranges, buffer/layout/role/mapping/state and active valid program; restore PATCH_VERTICES and all existing draw state. Reuse shared drawing through a private patch mode, without extending public ordinary primitive values.

Extend UBO stage namespaces to stage*8+slot only when the actual new stage/physical binding limits support them; preserve existing0..2 baseline capability and exact claim lifetime restoration. Revalidate new graphics stage UBO inputs before every graphics draw. Geometry/tessellation capabilities use actual context and optional patch entrypoint/native limits. SSBO additional graphics stages may be rejected if their reserved physical slots exceed hardware; retain documented0..2 contract unless tested separately.

Acceptance: public compile/bind geometry expands one point to a real4x4 quad with16samples; tessellated fullscreen triangle renders16samples and actualpixel; either pair order, unbind/release, nativepatchparameter restoration, transactional interface/link failure, unsupported/mismatched stages, invalid patches/mapped/range/state and optional gates. New stage UBO reflection/write/bind/mapping when supported; old compute/UBO/texture/MRT/query/instancing/shutdown regressions. DLL/handover/diff verification, one independent batch review, merge exact approved featurehead.

Review refinement: new-stage/patch draws require the current IGPU-owned successfully linked program; record native executable stage/primitive metadata at link success, preserving detach semantics and never inferring executable stages from attachments. Reject incompatible GS input and ordinary primitives with executable tessellation across every public draw family. External ordinary VS/PS programs remain supported; external advanced stages and caller relinking of owned programs are outside the contract.
