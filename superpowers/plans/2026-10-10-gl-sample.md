# OpenGL 最近点纹理采样实现计划

> **给执行的代理：** 必须使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，按任务逐个实现。步骤用复选框（`- [ ]`）跟踪。

**目标：** 让 OpenGL 探针里的 `igpu_draw_sampled` 把一张已经画好的 rgba8 纹理，用固定的最近点和钳制到边缘，采样进调用方当前的帧缓冲。左半边读回红 `255`，右半边读回蓝 `16711680`。采样器、混合、深度、光栅句柄仍必须是 0。

**架构：** 公开函数和门面已经存在。`igpu::draw_sampled` 在 `require_device` 之后调用 `Backend::draw_sampled`。Direct3D 在 `d3d11_impl::draw_sampled` 里绑着色器资源视图再调用普通绘制。OpenGL 的纹理不在那张表里，只在 `g_textures`。这一刀在 `gl_draw_sampled` 里查这张表，把纹理绑到当前的 `GL_TEXTURE_2D`（纹理单元保持 0），把当前程序里的 `uniform sampler2D igpu_tex` 设成 0，然后用和 `gl_draw` 相同的 `glDrawArrays` 画进当前帧缓冲。不创建采样器对象，不调用 `glActiveTexture`。Windows 的 GameMaker DLL 不编译 `native/gl/`。

**技术栈：** C++17，Windows `GL/gl.h` 加已经加载的 GL 2.0 入口，再加载 `glGetUniformLocation` 和 `glUniform1i`。WGL 探针，CMake 预设 `win-x64-release-vs18`，MSVC。编译进 MSVC 的 cpp 注释只用 ASCII。

**规格：** 用户在计划模式里选定的下一刀：最近点纹理采样。站立约束在 `SESSION_HANDOVER.md` 开头和「必须守住的结构」。`superpowers/specs/2026-10-06-slim-api-design.md` 不改。批准执行时，把本计划另存为 `superpowers/plans/2026-10-10-gl-sample.md` 并随第一个提交入库。

## 采样坐标

8×8 视口里，窗口坐标 `window = (ndc + 1) * 4`。这些数都是 1/8 或 1/64 的倍数，float32 能精确表示。`igpu_texture_read` 的 `y = 0` 对应 GL 行 `height - 1`。源纹理整列同色，所以 `v` 不影响这两个采样点。

| 纹素 (x, y) | 纹素中心的 ndc | 全屏 `u = (ndc.x + 1) / 2` | `u * 8` | 最近点纹素 |
|---|---|---|---|---|
| (1, 4) | -0.625 | 0.1875 | 1.5 | 1，红 |
| (6, 4) | 0.625 | 0.8125 | 6.5 | 6，蓝 |

源纹理用现有的顶点色四边形画成左红右蓝。左是纹素 0–3，右是纹素 4–7。

采样用的 6 个顶点，前 3 个是左下、右下、左上，盖住 `(1,4)`，盖不住 `(6,4)`。后 3 个盖住右边。

```text
(-1,-1) uv (0,0)
( 1,-1) uv (1,0)
(-1, 1) uv (0,1)
( 1,-1) uv (1,0)
( 1, 1) uv (1,1)
(-1, 1) uv (0,1)
```

最近点证明用另一张目标。6 个顶点盖住全屏，每个顶点的纹理坐标都是 `(0.484375, 0.5)`。`0.484375 * 8 = 3.875`，离纹素 3 的中心比离纹素 4 的中心近，读回必须是纯红 `255`。不要改这个坐标去迁就一次读回。若不是 `255`，先打印像素，再查过滤是不是被设成了线性。

着色器：

```glsl
#version 120
attribute vec2 in_pos;
attribute vec2 in_uv;
varying vec2 v_uv;
void main() {
  gl_Position = vec4(in_pos, 0.0, 1.0);
  v_uv = in_uv;
}
```

```glsl
#version 120
uniform sampler2D igpu_tex;
varying vec2 v_uv;
void main() { gl_FragColor = texture2D(igpu_tex, v_uv); }
```

属性 0 仍是 `in_pos`。属性 1 同时接受 `in_colour` 和 `in_uv`，因为没有一个程序两个都声明。位置加纹理坐标的步长是 16：`float2` 位置（usage `1`，type `2`）后面接 `float2` 纹理坐标（usage `4`，type `2`）。

                         std::int64_t first_vertex, std::int64_t vertex_count, std::uint64_t texture,
                         std::int64_t blend_state, std::int64_t depth_state, std::int64_t raster_state,
                         std::int64_t sampler_state)
    {
        GLenum mode = GL_TRIANGLES;
        if (!gl_draw_accepted("igpu_draw_sampled", primitive, blend_state, depth_state, raster_state, sampler_state,
                              mode))
        {
            return false;
        }
        const auto source = g_textures.find(texture);
        if (source == g_textures.end())
        {
            set_last_error("igpu_draw_sampled: unknown texture handle");
            return false;
        }
        const auto vertex = g_buffers.find(vertex_buffer);
        if (vertex == g_buffers.end())
        {
            set_last_error("igpu_draw_sampled: unknown buffer or layout");
            return false;
        }
        const auto layout_it = g_layouts.find(layout);
        if (layout_it == g_layouts.end() || layout_it->second != vertex->second.stride)
        {
            set_last_error("igpu_draw_sampled: the vertex buffer stride does not match the input layout");
            return false;
        }
        if (vertex->second.bind != 1 || vertex->second.stride <= 0)
        {
            set_last_error("igpu_draw_sampled: the vertex buffer was not created with IgpuBufferBind.Vertex");
            return false;
        }
        const std::int64_t vertex_total = vertex->second.size / vertex->second.stride;
        if (vertex_count < 0)
        {
            vertex_count = vertex_total - first_vertex;
        }
        if (first_vertex < 0 || vertex_count <= 0)
        {
            set_last_error("igpu_draw_sampled: the resolved vertex count is zero");
            return false;
        }
        if (first_vertex + vertex_count > vertex_total)
        {
            set_last_error("igpu_draw_sampled: the vertex range is outside the buffer");
            return false;
        }
        GLint program = 0;
        glGetIntegerv(GL_CURRENT_PROGRAM, &program);
        if (program == 0)
        {
            set_last_error("igpu_draw_sampled: no shader program is bound");
            return false;
        }
        const auto& fns = igpu_gl_fns();
        const GLint sampler = fns.GetUniformLocation(static_cast<GLuint>(program), "igpu_tex");
        if (g_vertex_array == 0)
        {
            fns.GenVertexArrays(1, &g_vertex_array);
        }
        GLint previous_array = 0;
        GLint previous_texture = 0;
        glGetIntegerv(GL_ARRAY_BUFFER_BINDING, &previous_array);
        glGetIntegerv(GL_TEXTURE_BINDING_2D, &previous_texture);
        glBindTexture(GL_TEXTURE_2D, source->second.texture);
        if (sampler >= 0)
        {
            fns.Uniform1i(sampler, 0);
        }
        fns.BindVertexArray(g_vertex_array);
        fns.BindBuffer(GL_ARRAY_BUFFER, vertex->second.id);
        bind_vertices(vertex->second, 0);
        glDrawArrays(mode, static_cast<GLint>(first_vertex), static_cast<GLsizei>(vertex_count));
        unbind_vertices();
        fns.BindBuffer(GL_ARRAY_BUFFER, static_cast<GLuint>(previous_array));
        fns.BindVertexArray(0);
        glBindTexture(GL_TEXTURE_2D, static_cast<GLuint>(previous_texture));
        return true;
    }
