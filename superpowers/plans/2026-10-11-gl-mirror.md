# OpenGL 镜像寻址实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 OpenGL 探针里的 `igpu_draw_sampled` 接受三轴都是镜像的采样器，在这一次绘制里把二维纹理的 S、T 包裹设成镜像重复，并在返回前写回绘制前的包裹和放大过滤。

**Architecture:** 公开函数已经存在。`igpu_sampler_state_create` 在 `igpu_gpu.cpp` 的门面里校验级数和各向异性。比较非 0 走 `sampler_state_create_compare`。各向异性大于 1 走 axes 那组虚函数。任一轴是边框走 `sampler_state_create_filters_border_range`。其余走到 `Backend::sampler_state_create_filters_range`。`GlBackend` 已经把这个虚函数转到 `gl_sampler_state_create_filters_range`。这一刀只放宽该函数接受的地址，并让 `gl_draw_sampled` 按记下的地址选 `GL_CLAMP_TO_EDGE`、`GL_REPEAT` 或 `GL_MIRRORED_REPEAT`。采样器句柄仍是 CPU 上的记录。`glTexParameteri` 改当前绑着的二维纹理，绘制后写回。句柄 0 不改包裹，也不改放大过滤。

**Tech Stack:** C++17，Windows `GL/gl.h` 加已经加载的 GL 2.0 入口。WGL 探针，CMake 预设 `win-x64-release-vs18`，MSVC。编译进 MSVC 的 cpp 注释只用 ASCII。

**Spec:** 这一刀的契约就是本计划。站立约束在 `SESSION_HANDOVER.md` 开头和「必须守住的结构」。`superpowers/specs/2026-10-06-slim-api-design.md` 不改。`spec.gmidl` 不改。

## 采样坐标

8×8 纹理，左半边纹素 0–3 是红 `255`，右半边纹素 4–7 是蓝 `16711680`。`igpu_texture_read` 的 `y = 0` 对应 GL 行 `height - 1`。源纹理整列同色，所以 `v = 0.5` 不影响这两个采样点。两边的目标纹素 `(1, 4)` 和 `(6, 4)` 必须读到同一个颜色，因为每个顶点的纹理坐标都相同。

最近点选纹素 `floor(u' * 8)`，`u'` 是包裹之后落在 `[0, 1)` 的坐标。镜像规则与 GL 和这块 Direct3D 11 设备一致：`floor(u)` 为偶数时取小数部分，为奇数时取 `1 - 小数部分`。小数部分是 `u - floor(u)`，负数也用这个式子。

| 调用 | `u` | 包裹后 | 结果 |
|---|---|---|---|
| 镜像，放大最近点 | `1.6f` | `0.4` 附近，纹素 3 | 红 `255` |
| 重复 | `1.6f` | `0.6` 附近，纹素 4 | 蓝 `16711680` |
| 钳制 | `1.6f` | 边缘纹素 7 | 蓝 `16711680` |
| 镜像 | `-0.625f` | `0.625`，纹素 5 | 蓝 `16711680` |
| 句柄 0，创建时的钳制和最近点还在 | `0.484375f` | 纹素 3 | 红 `255` |
| 镜像，放大线性 | `1.5f` | `0.5`，纹素 3 与 4 的交界 | `8388736` |
| 句柄 0 | `1.6f` | 边缘纹素 7 | 蓝 `16711680` |

`1.6f` 不是二进分数，实际值约是 `1.600000023841858`。镜像后约 `0.4`，乘 8 后落在纹素 3，不到纹素 4。`-0.625f` 是精确的 `-5/8`。不要改这些坐标去迁就一次读回。`u = 1.6f` 的镜像若读回蓝，先查 S、T 是不是仍停在 `GL_CLAMP_TO_EDGE` 或 `GL_REPEAT`。`u = -0.625f` 若读回红，先查负数是不是被收成了钳制。

公开创建参数：缩小和级间过滤是 `0`（`tf_point`）。镜像最近点的放大是 `0`，镜像线性的放大是 `1`。各向异性是 `1`。边框色是 `0`。比较是 `0`。级数偏移是 `0`，最细是 `0`，最粗是 `-1`。门面把最粗 `-1` 收成 `3.402823466e+38f` 再交给后端。地址 `0` 是 `IgpuAddressMode.Clamp`，`1` 是 `Repeat`，`2` 是 `Mirror`。三轴必须相同。W 轴只参加这个相等检查；二维纹理只改 S 和 T。
